# Product Overview

Cortex is a zero-knowledge cloud-based photo and video backup solution that prioritizes user privacy through client-side encryption. The system enables users to securely backup their media to AWS infrastructure while maintaining complete control over their data privacy.

## Core Principles

- **Zero-Knowledge Architecture**: Service provider has no access to unencrypted user data
- **Client-Side Encryption**: All encryption/decryption happens on the client device
- **Privacy-First**: Metadata, tags, and collections are all encrypted before storage
- **Multi-Device Support**: Users can access backups from multiple devices using encrypted key bundles

## Key Features

- Secure photo and video backup with client-side encryption
- Encrypted metadata management for organization and retrieval
- Tag-based organization using local image recognition
- Collection management for grouping related media
- Multi-device access with password-based key derivation
- Recovery key system for password recovery scenarios
- Direct S3 upload/download using presigned URLs for performance
